# Навигация по подготовке Sana

План рассчитан на одного разработчика с Codex и общий лимит кейса в пять часов. Рабочий Sana MVP уже находится в `main` командного GitHub-репозитория. Для следующего изменения возьмите свежую копию `main`; локальная история `starter-kit` была подготовительной.

| Когда | Документ | Для чего |
| --- | --- | --- |
| До старта | `docs/CASE_AUDIT.md` | Требования PDF, расхождения в источниках и состояние репозитория |
| Выбор демонстрационного кейса | `docs/IDEA_TOPICS.md` | Три темы образовательных задач с примерами карточек |
| До старта и первые 20 минут | `docs/START.md` | Настройка одного рабочего места и проверка доступа |
| В течение пяти часов | `docs/PLAN.md` | Последовательность работ, критерии, контрольные точки и демо |
| В течение пяти часов | `docs/CHECKLIST.md` | Проверка каждого требования и результата сдачи |
| Перед каждой задачей Codex | `docs/CODEX.md` | Как задавать работу, проверять изменения и коммитить |
| Контракт данных и API | `docs/CONTRACT.md` | Схема карточек, рейтинга, предложений и публичные маршруты |
| Инструкции по отдельным модулям | `docs/ROLE-*.md` | Подробные справочные промпты; написаны для разделения команды, используйте как справочник, а не как план работы в одиночку |
| Инструкции агента | `AGENTS.md` | Ограничения проекта для Codex |

## Критерии кейса

| Критерий PDF | Баллы |
| --- | ---: |
| Геймификация бизнеса | 25 |
| Сквозной сценарий | 20 |
| Качество карточки | 15 |
| Каталог и отклики | 15 |
| AI-функция | 10 |
| Техническое качество | 10 |
| Демонстрация | 5 |

## Пять запретов продукта

1. Не добавлять в карточку факты, которых пользователь не сообщал.
2. Не публиковать без явного подтверждения бизнеса.
3. Не назначать команду автоматически.
4. Не скрывать и не блокировать отклики на задачу из-за низкого рейтинга.
5. Всегда показывать рейтинг с разбивкой и тем, что можно добавить.

Схема баллов за подтверждённый этап описана в `docs/CONTRACT.md`: сейчас это проектное допущение в 10 баллов. Перед сдачей уточните число у организаторов.
