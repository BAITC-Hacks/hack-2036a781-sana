# Үш білім беру тақырыбы

Бұл үш тақырып — Sana ашық каталогына енгізетін демонстрациялық бизнес-тапсырмалар. Олар Sana MVP-ін алмастырмайды. Әр нұсқада бірдей негізгі ағын сақталады: черновик → AI нақтылау сұрақтары → адам өңдеп растайтын карточка → дайындық рейтингі → ашық каталог → команда ұсынысы → бизнестің қолмен шешімі.

Төмендегі деректер мен байланыс үлгілері синтетикалық. Табыс өлшемдері кейстің талабы емес, бизнес-өкіл карточкада ұсынуға тиіс мысалдар; демонстрацияда оларды келісілген талап деп көрсетпеңіз.

## 1. EduFeedback — Python тапсырмасына кері байланыс

**Неге бұл нұсқа:** мәселе бірден түсінікті, студенттерге практикалық жоба беруге болады, ал нәтижені шағын дерек жиынында тексеруге болады. AI баға қоймайды және мұғалімнің шешімін алмастырмайды.

| Карточка өрісі | Мысал мазмұны |
| --- | --- |
| Тақырып | Python тапсырмаларын тексеруге мұғалімге көмек |
| Контекст | Онлайн мектепте оқушылар Python бойынша үй жұмысын жібереді, оқытушылар әр жұмысты қолмен қарайды. |
| Қажеттілік | Мұғалім жиі кездесетін қателерді тез табуға көмектесетін құрал іздейді. |
| Пайдаланушылар | Python оқытушылары және оқу бағдарламасына жауапты әдіскерлер. |
| Деректер мен материалдар | Жеке деректері алынған синтетикалық код мысалдары, тапсырма мәтіндері және мұғалім бекіткен рубрика. |
| Шектеулер | Құрал автоматты баға қоймайды; мұғалім әр ұсынысты өзі қарайды; оқушыны анықтайтын дерек қолданылмайды. |
| Күтілетін нәтиже | Қате санаттарын бөліп, мұғалім өңдеп бекітетін қысқа кері байланыс жобасын ұсынатын прототип. |
| Табыс критерийлері | Мысал ретінде: мұғалім сынақтағы 30 жұмыстың кемінде 24-індегі ұсынысты пайдалы деп бағалайды; уақыт үнемі бөлек өлшенеді. |
| Байланыс тұлғасы | Жобаға жауапты әдіскер; сұрақтар синтетикалық демода форма арқылы беріледі. |
| Өзара әрекет форматы | Аптасына бір қысқа онлайн талқылау және рубриканы бекітуге арналған кері байланыс. |

## 2. QazaqStudy — екі тілдегі оқу материалын түсіндіру

**Неге бұл нұсқа:** қазақ және орыс тіліндегі оқу материалдарын қолданатын білім беру ұйымына нақты мәселе береді. Нәтиже бастапқы материалға сүйеніп, дереккөзін көрсетуі керек.

| Карточка өрісі | Мысал мазмұны |
| --- | --- |
| Тақырып | Қазақша және орысша материалдардағы терминдерді түсіндіру |
| Контекст | Курста бір тақырыпқа қатысты түсіндірмелер мен терминдер бірнеше құжатқа бөлініп сақталған. |
| Қажеттілік | Студентке түсініксіз терминді курс материалынан тауып, екі тілде қысқа түсіндіру қажет. |
| Пайдаланушылар | Қазақ және орыс тілінде оқитын студенттер мен курс авторлары. |
| Деректер мен материалдар | Ұйым бекіткен синтетикалық сабақ мәтіндері, терминдер сөздігі және екі тілдегі түсіндірмелер. |
| Шектеулер | Жауап тек берілген материалдан құралады; дереккөз көрсетіледі; табылмаса жүйе ойдан қоспай, материалда жоқ екенін айтады. |
| Күтілетін нәтиже | Материалдан терминді тауып, қысқа түсіндірме мен бастапқы бөлімге сілтеме беретін прототип. |
| Табыс критерийлері | Мысал ретінде: сынақ сұрақтарының кемінде 9/10-ына дұрыс бөлім сілтемесі беріледі; жауапты курс авторы тексереді. |
| Байланыс тұлғасы | Курстың контентіне жауапты редактор; байланыс синтетикалық демода Sana ішіндегі форма арқылы жүреді. |
| Өзара әрекет форматы | Аптасына бір тексеру сессиясы; курс редакторы терминдер мен дереккөз сәйкестігін қарайды. |

## 3. CampusLab — зертхана уақытын жоспарлау

**Неге бұл нұсқа:** AI-дан тыс шешімдер ұсынатын командаларға да ашық практикалық тапсырма. Жұмыс барысын нақты брондау сценарийімен көрсету оңой.

| Карточка өрісі | Мысал мазмұны |
| --- | --- |
| Тақырып | Университет зертханасындағы құралдарды алдын ала брондау |
| Контекст | Бірнеше курс бір зертхана мен құралдарды қолданады; бос уақытты қазір кестелерден қолмен салыстырады. |
| Қажеттілік | Қай құралдың қай уақытта бос екенін көріп, қайталанатын брондауды болдырмау керек. |
| Пайдаланушылар | Зертхана үйлестірушісі, оқытушылар және практикалық сабақ жүргізетін студенттер. |
| Деректер мен материалдар | Синтетикалық сабақ кестесі, құралдар тізімі, қолжетімді уақыт аралықтары және брондау ережелері. |
| Шектеулер | Нақты студент деректері қажет емес; құралға бір уақытта бір ғана брондау рұқсат етіледі; бастапқы кестені әкімші бекітеді. |
| Күтілетін нәтиже | Бос уақытты көрсетіп, қақтығысы жоқ брондау жасауға мүмкіндік беретін веб-прототип. |
| Табыс критерийлері | Мысал ретінде: сынақ сценарийлерінде бір құралға бір уақытқа қосарланған брондау болмайды; қолданушы бос уақытты екі минут ішінде табады. |
| Байланыс тұлғасы | Зертхана үйлестірушісі; аты-жөні мен нақты контакті демонстрациялық дерекке енгізілмейді. |
| Өзара әрекет форматы | Аптасына бір рет кесте иесімен демо және ережелерді растау. |

## Таңдау

Демо үшін **EduFeedback** тақырыбын ұсынамын: мәселе мен қолданушылар түсінікті, қажетті деректерді синтетикалық жасау оңай және мұғалімнің соңғы шешімін сақтау арқылы адам бақылауы анық көрінеді. AI-ға оқушы жұмысын бағалатпай, Sana AI-сын бизнес-черновикті нақтылау мен карточканы жинауға қолданыңыз.

Қай тақырып таңдалса да, бизнес тапсырмасының рейтингі мен таңдалған команданың нақты прогресі үшін берілетін ұпайды бөлек көрсетіңіз. Кейс прогресс үшін ұпайды атайды, бірақ оның нақты мөлшері мен растау ережесін анықтамайды; оны ұйымдастырушылардан нақтылаған жөн.
